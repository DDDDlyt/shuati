# 用 GitHub Pages 托管「刷题总台」· 零基础教程

把本仓库里的 `index.html`（刷题总台网页）变成一个**谁都能打开、不用登录**的公开网址，形如：

```
https://你的用户名.github.io/shuati/
```

---

## 先看清一件事（很重要，别白忙）

| 事实 | 说明 |
|---|---|
| GitHub Pages **功能还在**，能出真网址 | 这点比 Gitee 强——Gitee Pages 2024 年已下线 |
| 但 `*.github.io` 的网址**在国内访问不稳定** | 有时秒开、有时转圈、有时打不开，跟时段和网络有关 |
| 你自己的 Gitee 仓库已经跑通了 | `gitee.com/lin-yuan-t/shuati`，Git 全流程你练过了 |

**所以这条路的真实定位**：练手 + 攒一个「我做过网站」的作品，申请研究生时可以对导师说「我自己写了个刷题工具，托管在 GitHub 上」。**日常刷题还是用资料库那个链接**（我更新、你刷新，最省事）。

## 你现在已经有的东西（省一大截功夫）

你电脑上的 `D:\shuati` **已经是一个 Git 仓库了**，而且已经提交过、已经推到了 Gitee。

**所以这次不用 `git init`，不用重新 `add` 一遍。** 只需要：

2. 加一个 GitHub 的远程地址（叫 `github`，跟 `origin` 并存）
3. 推上去

这样你一个本地仓库同时推两个平台，这是真实工作里的常见做法，比重新建仓库更值得学。

## 第一步：注册 GitHub（这步只能你自己做）

1. 浏览器打开 **https://github.com** → 右上 **Sign up**
2. 填邮箱 → 设密码 → 起用户名
3. **用户名要想清楚**，它会变成你网址的前缀，而且**基本改不了**：
   - 只能英文、数字、短横线
   - 建议 `linyuantong`、`yuantong-lin`、`lyt-bio` 这种，别用 `abc123`
4. 收验证邮件（**翻一下垃圾邮件箱**），点激活

> 打不开 github.com 就先放着，等你网络顺的时候再试。注册这步没有任何技巧，纯看网络。

## 第二步：建仓库

1. 登录后右上角 **`+`** → **New repository**
2. **Repository name** 填 `shuati`
3. 选 **Public**（Pages 免费版只支持公开仓库）
4. 下面三个初始化选项（Add a README / .gitignore / license）**全部不勾**
5. **Create repository**

---

## 第三步：生成 Personal Access Token（推送的密码）

GitHub 从 2021 年起就不允许用账号密码推代码了，必须用令牌。

1. 右上角头像 → **Settings**
2. 左侧拉到最底 **Developer settings**
3. **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**
4. Note 随便写 `push`；Expiration 选 90 days
5. 权限勾 **`repo`**（这一项就够）
6. **Generate token** → 页面显示 `ghp_xxxxxxxx` 一串 → **立刻复制**，关掉页面就再也看不到

> ⚠️ 令牌 = 你账号的钥匙。别发截图、别提交进仓库。**泄露了就去同一个页面 Revoke 掉重新生成。**

## 第四步：更新本地的 index.html（关键一步，别跳）

你 `D:\shuati` 里的 `index.html` 是**旧版（556 张卡）**，现在题库已经涨到 **1662 张（16 个题库）**。

1. 下载本目录下的 `index.html`
2. 覆盖 `D:\shuati\index.html`（同名的直接替换）
3. 在 `D:\shuati` 空白处右键 → **Git Bash Here**

## 第五步：加一个 GitHub 远程，推上去

在 Git Bash 里，**逐条敲**（把用户名换成你 GitHub 的）：

```bash
git status
```

应该看到 `modified: index.html`（说明替换生效了）。接着：

```bash
git add .
git commit -m "题库更新到 1662 张（16 个题库）+ 手写笔作答"
```

然后加远程（**两个远程并存，`origin` 还是 Gitee，`github` 是新加的**）：

```bash
git remote add github https://github.com/你的用户名/shuati.git
```

最后推（令牌我留了占位，**换成你那串 `ghp_...`**）：

```bash
git remote set-url github https://你的用户名:ghp_你的令牌@github.com/你的用户名/shuati.git
git push -u github main
```

成功的样子：

```
To https://github.com/你的用户名/shuati.git
 * [new branch]      main -> main
```

> 为什么直接把令牌写进地址？因为 Git 凭据管理器的弹窗经常不听话（你上次在 Gitee 就踩过这个坑），写进 URL 最省事。**代价是令牌明文存在 `.git/config` 里**，这台电脑是你自己的，问题不大；哪天不想留了，执行 `git remote set-url github https://github.com/你的用户名/shuati.git` 就清掉了。

---

## 第六步：开 Pages

1. 浏览器打开 `https://github.com/你的用户名/shuati/settings/pages`
2. **Source** 选 **Deploy from a branch**
3. **Branch** 选 **`main`**，目录选 **`/ (root)`**
4. 点 **Save**
5. 等 1～3 分钟（首次构建要排队），刷新页面，顶部会出现：

```
Your site is live at https://你的用户名.github.io/shuati/
```

点开就是你的刷题总台。

> 手机打不开先别急，多半是 `github.io` 在国内不通。换 WiFi / 换时段再试，或者在电脑上打开确认页面本身是好的。

## 以后更新（日常三连）

```bash
git add .
git commit -m "更新：加了新题"
git push github main
```

**GitHub Pages 会自动重新构建**，等一分钟刷新就是新版——这点比 Gitee 省事（Gitee 要手动点「重新部署」）。

如果还想同步推 Gitee：

```bash
git push origin main
```

一个仓库，两个平台，两条命令。

## 常见坑

| 现象 | 原因 / 解决 |
|---|---|
| `remote: Permission denied` / `403` | 令牌没勾 `repo`，或用户名写错。重新生成令牌 |
| `remote github already exists` | 已经加过了，改用 `git remote set-url github ...` |
| `src refspec main does not match any` | 本地没这个分支，`git branch -M main` 后再推 |
| Pages 一直 404 | 等 3～5 分钟；确认 Branch 是 main、目录是 root；确认 `index.html` 在仓库根目录 |
| 网页空白 | 仓库根目录没有 `index.html`，或文件名大小写不对 |
| `github.io` 打不开 | 国内网络问题，不是你的错。换网络/时段，或直接用资料库链接 |
| 想删掉存进 `.git/config` 的令牌 | `git remote set-url github https://github.com/你的用户名/shuati.git` |

| 按钮 | 作用 |

| 笔 | 红色随手划重点 |

- 批注按**知识点 / 题目**分别保存，退出再进来还在；换设备、换字号都能对齐（坐标按百分比存）
- 批注跟着**云同步**走，平板上划的，手机上看得到
- 体积参考：一个知识点划 20 笔大约 15 KB

## 手势和手写不打架（v19 修复）

以前在批注/手写板上画横线，一划超过 70px 就被当成「左滑翻页」，题目被翻走。v19 改成：

- **画布上的触摸一律不算翻页**（`touchstart/touchend` 在 canvas 上直接截断，不冒泡到全局）
- 全局翻页判定收紧：位移 ≥95px、斜度 ≤0.55（斜着划过不算）、用时 <650ms（慢慢拖不算）、多指手势全忽略
- **手写板打开期间，任何滑动都不翻页**
- **笔正在写时，手掌/手指的触摸被吃掉**，既不滚页也不翻页（palm rejection）
- 输入框、下拉框里横向拖动不翻页

翻页要在**退出批注**（点 ✏️）之后做，或者直接点底部「下一题 →」。

## 砍掉每日任务和打卡（v20）

之前首页有一块「今日任务：新题 10 张 / 复习 20 张 + 连续打卡 🔥」。它的问题是：**配额是给你看的，不是给你用的**。刷到 9/10 你会停，刷到 30/20 也没有额外收益，连续天数断一天还会有负罪感——这些都不产生知识。

v20 改成：

| 位置 | 现在是什么 |
|---|---|
| 右上角数字 | **今天该复习几张**（到期卡数量），点一下直接开始 |
| 中间大卡 | 一个按钮，永远指向「现在最该做的事」：<br>有到期 → `开始复习 N 张`<br>没到期但有新题 → `开始 20 张新题`<br>都刷完了 → `随机 20 题` |
| 设置页 | 「每日目标」两个输入框已删（不再需要） |
| 统计页 | 「连续打卡」改叫**连续学习**：当天只要答过一题就算，不看你有没有达标 |

打卡日历还在统计页，但它只记录「这天学过没有」，不记录「这天达没达标」。

## 知识点专攻清单（v20）

知识体系页顶部原来是「漏洞诊断 top 5」，现在是 **39 个知识点全排序**：

## 按章节精讲（v21）

知识体系页顶部多了一个入口：**📖 按章节精讲 · 14 章通读**。

这不是又一份知识点卡片，是能从头读到尾的讲义：

| 层级 | 内容 |
|---|---|
| 学科 | 生物化学 / 遗传学 / 英语 CET-6，顶部胶囊切换 |
| 章节 | 14 章。每章一张卡，显示「几个知识点 · 几道题」，读过的打 ✓ |
| 章首 | **「这章在讲什么」**——一段话讲清主线、考点、和前后章的关系（这 14 段是手写的，不是拼的） |
| 正文 | 每个知识点一节：讲透版正文 + 关键词 + ⚠️ 易错 + 🧠 口诀，正文里的专业词仍然可以点开查 |
| 章尾 | `读完，刷本章 N 题` + 上一章 / 下一章 |

几个细节：

- **接着读**：目录顶部会有一张「接着读：糖代谢」，点它直接落回上次停的那一行（滚动位置按章记录）
- **可以勾画**：每章右下角有 `✎` 批注条，笔 / 荧光笔 / 橡皮，批注按章保存、跟云同步走；开着批注时手指只画不滚动，退出后恢复
- **刷题时也能跳**：每题右上角有 `📖 讲解`，点了直接跳到这道题所属知识点在讲义里的位置，按 ← 原路返回那道题
- **每节底部有 `刷这 N 题`**，读完一个点就能立刻做它对应的题，不用回题库找
- 阅读进度跟着云同步走，平板上读到哪，手机上也记得

怎么用：**先把一章读一遍再刷这一章的题**，比直接刷题快——刷题是检验，讲义是建立框架，顺序反了会一直在「这个我好像见过但想不起来」的状态里打转。

## 看不懂题怎么办（v11 新增，两件事）

### ① 题干里的专业词，点一下就有解释

蓝色虚线下划线的词都能点，弹出人话解释 + 关联知识点。**179 条**术语，覆盖生化、遗传、英语写作的高频卡点：别构酶、米氏方程、Km、Tm、操纵子、倒位环、cGMP、SAM…

> 为什么做成这样：你说「四个选项都不认识」「都不知道题目什么意思」——这不是懒，是**术语没过关**。题目里的名词不认，选项再简单也是天书。所以任何一道题，先查词，再谈对错。
> 知识页顶部还有「📖 打开术语表」，179 条可以搜。

### ② 蒙对的题，不算你会

以前选了 A 碰巧对了，系统就记「掌握」，然后三个月不再考你——这是刷题软件最坑的地方。

现在：**选择题答对之后，会停一下问你「真会 / 蒙的」**

- 点 **✅ 真会** → 正常记掌握，进入间隔重复
- 点 **🎲 蒙的** → **不算掌握**、打回最底层、**当天再考你一次**，统计里单列「🎲 蒙对未掌握」
- 已经连对 2 次的老熟人不再追问，不拖慢节奏
- 统计页那个「🎲 蒙对未掌握 N 张」点一下就进重考队列

> 判定逻辑：`st` 只有「真会」才置 1。蒙对记 `st=0 + g+1`，所以知识点掌握度、漏洞诊断、掌握率全都不认它。想糊弄系统，只能糊弄自己。

## 分享给别人（访客模式）

设置页「🔗 分享给别人」→ 复制访客链接（`...?guest=1`）。

对方打开后：
- **看不到云同步那一块**，没机会碰你的令牌
- 只能刷题、看知识、看钩子、查术语
- 他的进度存在他自己浏览器里，跟你完全隔离

链接怎么发都安全（页面里没有令牌，仓库是公开的、数据仓库是私有的）。**别把设备借人**——令牌在那台设备的浏览器里。

## 记忆钩子怎么用（v10 新增，直接冲着「记不住」来的）

刷题最大的问题不是不会，是**记不住**：这题看懂了，三天后再考还是错。钩子就是给每个考点配一句能挂在脑子里的短句——不是把答案再念一遍，而是抓那个「一错就错在这」的点。

**281 条钩子，分两层：**

| 层级 | 数量 | 长什么样 |
|---|---|---|
| 知识点总钩 | 39 条（每个知识点 1 条） | 「α：3.6 步一圈、一圈 0.54、一步 0.15」——把一整块压成一句 |
| 考点钩 | 242 条 | 「0.34 是 DNA 的碱基对！β 折叠链间距约 0.47」——专治易混 |

**三个地方会遇到它：**

1. **答完题翻答案**：钩子永远排在解析**前面**（琥珀色那块），因为你更需要的是「怎么记住」，不是「为什么错」。
2. **知识点详情页**：整块的总钩 + 该块所有考点钩，一次性摆出来。
3. **⚡ 钩子墙**（知识页顶部按钮）：两种模式
   - **全部钩子**：按学科 → 知识点排好，当背诵清单用
   - **钩子自测**：只给题干，不给钩子。先自己回忆口诀，再点「👀 揭开钩子」对一下——这才是主动回忆，比反复看有效得多

> 覆盖：**756 张题**有专属钩子（一题一条，按题干关键词精确匹配，不硬凑）；剩下的题显示所属知识点的总钩，标注「本块总钩」。
> 英语那 249 个单词没有逐词编钩子——硬编会变成瞎联想反而记错。词根表（spect/port/dict/tract…）放在钩子墙里，按词根一串一串记。

顺带修了个事实错误：原知识点里把 0.34 nm 写成 β 折叠链间距（那是 B-DNA 的碱基对间距，β 折叠约 0.47 nm），已改。

## 知识体系怎么用（v8 新增，你最该看的一节）

**它解决的是「刷完不知道漏在哪」这个事。**

打开底部 **📖 知识**，会看到 39 个知识点，按「学科 → 章 → 知识点」排好：

| 学科 | 章 | 知识点数 |
|---|---|---|
| 生物化学 | 蛋白质 / 酶 / 糖代谢 / 脂代谢 / 核酸与分子生物学 | 22 |
| 遗传学 | 孟德尔互作 / 连锁染色体 / 突变群体 / 微生物分子 / 技术与发育 | 13 |
| 英语 | 词汇 / 听力 / 写作 / 翻译 | 4 |

每个知识点都有三块内容：**讲透它**（正文，把机制串起来）、**关键词**（看到这些词就该想到它）、**你最容易在这里栽**（易错点，都是判断题/选择题的高频陷阱）。

### 三个入口，按使用场景选

1. **刷题时**：答错后不再「唰」地跳下一题，而是**停下来**显示正确答案 + 这个知识点是什么 + 「展开讲解」，看完再点「下一题」。
2. **打开首页**：顶部会有一张橙色卡「⚠️ 你现在最虚的一块」，直接告诉你是哪个知识点、错几张、掌握多少，点进去就是讲解。
3. **知识页顶部「漏洞诊断」**：按「错题数 + 学过但没掌握」排序的前 5 名，每条带一句"你为什么会错"，点进去看讲解 → 按钮「刷这块 / 只刷错题」。

> 判定规则：某个知识点下 ①错题 ≥1 且累计学过 ≥3 张 ②错得越多、学过没掌握越多，排得越前。**完全没碰过的知识点不算漏洞**，算"没开始"，不会来烦你。

### 想让我给你讲 → 点「一键复制漏洞报告」

统计页底部 / 知识页都有这个按钮，点一下复制出一段文字（你哪些知识点错多少、易错点是什么），**直接粘给我**，我按严重程度一条条给你讲。这是这套东西和"AI 讲题"之间唯一的接口，很好用。

题目覆盖：**1599 / 1662 张**卡已挂到知识点上（一卡可挂多个），剩 63 张是超纲名解和生物膜、细胞周期这类拓展内容，不影响刷题。

## 云同步怎么配（v7 新增，平板 ⇄ 手机）

**一次配置，以后全自动。**

1. 平板/手机打开刷题总台 → **设置** → 找到「☁️ 云同步（GitHub 私有仓库）」
2. **令牌**：填你的 GitHub 令牌（`ghp_` 开头，勾了 `repo` 权限那个）；**仓库**可以留空
3. 点 **连接并同步** —— 会自动创建私有仓库 `你的用户名/shuati-data` 并上传
4. 勾上 **自动同步**（每 60 秒静默同步，切后台也会补一次）
5. 另一台设备重复 1-3 步，进度和笔迹就对齐了

> 数据存在**你自己的私有仓库**里，别人看不到；令牌只存在本机浏览器，**不会上传、不会写进同步文件**（这点做了测试验证）。
> 不想用了点「断开」，本机数据不删。

**传输是压缩的（v17）**：`shuati-sync.json` 里放的是 gzip 后的内容（3 字节头 `GZ1` + gzip 流，再 base64）。
实测 600 张卡 + 300 条笔迹 + 80 条批注 = 2.23 MB 原始 JSON → 上传请求体 **0.45 MB（20%）**，拉回来坐标一位不差。
老版本留下的明文 JSON 云端文件也能照常读，不用手动迁移。上传体超过 200 KB 时超时放宽到 90 秒。

**为什么笔记不能靠「复制数据」搬**：笔迹是逐点坐标，几百条笔迹就是 2–4 MB，光靠剪贴板要切成 300 多段。
笔记走云同步，复制那条路只适合搬答题记录。

**不联网的备选**：设置页「📁 手动互传」，两条路：

- **在浏览器里**（Chrome / Safari）：点「导出文件」得到一个 `.json`，发到另一台设备「选择文件导入」。
- **在微信里**：微信内置浏览器不许网页下载文件，点「导出文件」会被甩到系统浏览器——那是另一个空存储空间，导出来是空的。所以微信里用「📋 复制数据」：弹出的是**一段文本**，复制发给自己或「文件传输助手」，另一台设备点「📥 粘贴导入」。
  - 两种包：**「只要答题记录」**（默认，卡片压成数组，不带笔迹和批注）和**「连笔迹一起」**。前者体积约后者的 1/3。
  - **压缩自带**：微信 X5 内核没有 `CompressionStream`，会自动懒加载 `pako.min.js` 顶上（前缀 `PK:`），不再退回原文 base64——同一批数据从 232 段降到 4 段。
  - 数据长会自动切成多段（每段 2600 字符），一段段发、一段段粘，会自己拼起来；超过 15 段会直接建议改用云同步。
  - 复制时沾上的空格、换行、全角空格、甚至开头前缀被吞（按 gzip 魔数认回来），都能自动清理救回来；真少了一截会明说「数据不完整」，不会瞎导。

## 笔画断点自动续接（v23）

手写笔接触不良（笔尖快速移动时短暂离屏）会把一笔断成一串点。现在：

- 抬笔到落笔间隔很短（<200ms）、离上一停点很近（<50px）、且粗细/橡皮没变 → 自动当作同一笔续上，笔画间平滑连线
- 停顿超过 200ms、或落点离上一点很远 → 仍算新的一笔，不会误连
- 批注（勾画）同样支持，阈值按画布比例换算

### 🎯 模考（首页「模考 · 计时交卷」）

| 卷型 | 组成 | 时间 |
|---|---|---|
| 834 全真卷 | 名解 6（各 3 分）· 简答 4（各 8 分）· 判断 10（各 1 分）· 选择 10（各 1.5 分）· 填空 10（各 2.5 分） | 120 分钟 |
| 期中快测 | 课堂层 20 题，每题 5 分 | 30 分钟 |
| 10 题小测 | 只抽选择/判断/填空，交卷立刻出分 | 10 分钟 |

- 顶部倒计时，剩 5 分钟变红闪烁；时间到自动交卷
- 题号可点「答题卡」跳转，看哪几题空着
- **客观题自动判分**；名解/简答/论述交卷后逐题「对照答案 → 自评：不会 0 / 写了一半 / 基本全对」
- 交卷后给出「这张卷子最该补的 3 个知识点」，点「刷」直接进补漏
- 成绩存在统计里，选卷页能看到最近 5 次
- 中途退出 = 弃考，不记成绩（不给「假装考完了」留口子）

### ⌨️ 拼写（设置页「拼写 30 个」）

CET-6 那 249 个词 + 60 个听力场景词，以前只有选择题——**认得出 ≠ 写得出**。现在：

- 给中文释义 + 首字母 + 字母数，把英文打出来
- 差一个字母算过（提示「差一个字母」），差两个才算错
- 每个词有 🔊 听写、💡 提示（多露一个字母）
- 打错的词当天打回最底层，明天会再考
- 单词卡上方也有「⌨️ 练这个词的拼写」，单个词直接进拼写

### 🔈 朗读（浏览器自带，不联网）

有英文的卡片右上角多一个 🔊，答案区有「🔊 念一遍答案」。设置页可调 0.7× / 1.0× / 1.25× 语速。

### 🩸 顽固卡（统计页）

同一张卡错满 4 次（或蒙对 5 次）自动进「顽固卡」区。这类题**原样再背一遍多半还是错**，所以给两个动作：

- **看**：跳到这张卡，先看记忆钩子换个记法
- **压 30 天**：这一个月先不出现，别让它天天消耗你
- 答对一次错误计数会减一，自己会好，不会永久钉在名单上

### 📕 错题本（统计页「错题本」）

按知识点分组，题干 + 答案 + 提示，**可以直接打印 / 存 PDF**（打印时自动转白底黑字，导航和按钮不印）。考前打一叠纸，比在手机上翻有效。

第一部分 氨基酸与蛋白质

第一章 氨基酸

1.1 蛋白质的元素组成与含量计算

  • ◇ 蛋白质都是由氨基酸通过肽键相连而成的含氮有机化合物。
  • 元素组成：C、H、O、N、S（N 占 10%~40%，荧光笔标）。
  • 各种蛋白质含氮量很接近，平均 16%（红笔）。
  • ★ 粗蛋白含量 = 蛋白质含氮量 × 6.25（6.25 = 1/16%，红笔注：N=16%）。
  • 蛋白质的大小顺序：蛋白质 — 多肽（分子量 1000~5000，20~100 残基）— 氨基酸。
  • 蛋白质的生物学功能（6 条）：1) 催化剂（酶）2) 代谢调节 3) 免疫保护 4) 细胞内的转运和储存 5) 运动支持 6) 细胞间信息传递。

1.2 蛋白质水解

  • 完全水解（酸/碱）→ 氨基酸混合物；部分水解（酶解）→ 多肽 + 氨基酸混合物。
  • 酸水解：色氨酸被破坏；含羟基氨基酸（丝、苏）部分被水解；天冬酰胺、谷氨酰胺的酰胺基被水解下来（脱氨，红笔划线）。
  • 碱水解：发生外消旋作用，但色氨酸不被破坏。
  • 酶水解：优点——氨基酸不被破坏、不易发生消旋；缺点——水解不完全，中间产物多。

1.3 氨基酸结构

  • α-氨基酸通式：中心 C 连 R、NH₂、H、COOH。
  • 组成蛋白质的氨基酸有 20 种，均属 L-α-氨基酸（甘氨酸除外，无手性——红笔）。
  • 各种 AA 的差异体现在 R 基上。
  • ★ 含特殊基团的氨基酸（红笔重点）： 1. 含 -OH：丝氨酸、苏氨酸、酪氨酸 2. 含 S：半胱氨酸、蛋氨酸（甲硫氨酸） 3. 含杂环：色氨酸、组氨酸 4. 含酰胺基：天冬酰胺、谷氨酰胺
  • 非蛋白质氨基酸：大多是标准 α-AA 存在于体内，有些是 β-、γ-、δ-、D-型。存在意义：1) D-AA 存在于细菌细胞壁（肽聚糖）和某些抗生素中；2) 作为代谢中间物的非蛋白质氨基酸（如鸟氨酸、瓜氨酸）；3) 蛋白质翻译后修饰产生（如羟脯氨酸、羟赖氨酸）；4) 作为体内氨的转运和储存载体；5) 调节生物体功能（如甘氨酸是抑制性神经递质）。

1.4 L 型与 D 型的区别

  1. 旋光/构型不同：Fischer 投影中 D 型氨基在右，L 型氨基在左（-COOH 都在上端）。
  2. 组成的蛋白质不同：D-AA 只参与细菌细胞壁等的合成；天然蛋白质由 L-AA 组成。
  3. 含量不同：D 型少；生物体蛋白质中均由 L 型组成（红笔下划线）。

1.5 氨基酸的两性解离与等电点 pI ★

  • 氨基酸在结晶态或水溶液中以兼性离子（两性离子）形式存在。
  • ◇ pH > pI：氨基酸带负电；pH < pI：带正电（红笔）；pI 时净电荷为零，呈电中性，在电场中不移动。
  • Gly 的三级解离式：⁺H₃N—CH₂—COOH ⇌ ⁺H₃N—CH₂—COO⁻ ⇌ H₂N—CH₂—COO⁻（标 pK₁、pK₂）。
  • ★ pI = ½(pK₁ + pK₂)（红笔「背」）。红笔注：pI 一定小于 pK₂、一定大于 pK₁（对侧链不带电的 AA 而言）。
  • 推导：GlyH₂⁺ ⇌ Gly± + H⁺（k₁）；Gly± ⇌ Gly⁻ + H⁺（k₂）；pI 时 [Gly⁺] = [Gly⁻]，得 [H⁺]² = k₁·k₂，pH = ½(pK₁+pK₂)。
  • 蓝笔小字：H⁺ 带正电、OH⁻ 带负电、R 基不同则电性不同。

1.6 氨基酸的特征化学反应

★ α-羧基和 α-氨基参加的反应（红笔◇重点）：

  1. 茚三酮反应：α-氨基酸的游离 α-氨基与水合茚三酮共热，生成蓝紫色化合物，在 570 nm 处有吸收峰（脯氨酸、羟脯氨酸生成黄色化合物，430 nm）。
  2. 成肽反应：应用——氨基酸自动分析仪的检测原理。

1.7 常见氨基酸缩写与分类

  • 三字母缩写表：Ala 丙、Arg 精、Asn 天冬酰胺、Asp 天冬、Cys 半胱、Gln 谷氨酰胺、Glu 谷、Gly 甘、His 组、Ile 异亮、Leu 亮、Lys 赖、Met 甲硫（含硫）、Phe 苯丙、Pro 脯、Ser 丝、Thr 苏、Trp 色、Tyr 酪、Val 缬；Sec 硒代半胱氨酸（红笔注：第 21 种氨基酸）。
  • ★ 五种分类（红笔「背」）： 1. 非极性脂肪族（侧链仅 C、H）：甘、丙、缬、亮、异亮、脯 2. 极性中性（侧链有极性不带电）：丝、半胱、苏、天冬酰胺、谷氨酰胺、酪 3. 芳香族：苯丙、色、酪 4. 酸性（侧链含可解离负电基团）：天冬、谷 5. 碱性（侧链含可解离正电基团）：赖、精、组（红笔划线）
  • ◇ 特殊的氨基酸——半胱氨酸（红笔注：二硫键）：两个半胱氨酸的 -SH 脱氢形成 S—S 二硫键（红笔划线）。二硫键使相邻肽段（蛋白质）的结构更稳定（红笔「背」）。

第二章 蛋白质的结构

〔便利贴〕考点：一级~四级结构及其作用力（大题 1/4）；方向性；理化性质；结构域、模体（名词解释）；「构象、构型」。

2.1 结构层次总览

  • 一级结构 → 二级结构 → 三级结构 → 四级结构；二、三、四级统称空间结构（高级结构）。

2.2 一级结构 ★

  • 广义定义：蛋白质一级结构 = 多肽链中氨基酸的排列顺序 + 二硫键的位置（红笔）。
  • ☆ 维持一级结构的化学键：肽键、二硫键（※）。
  • 氨基酸残基：肽键中的氨基酸因参与成肽已不是完整的氨基酸，称氨基酸残基（红笔【重点】）。
  • 肽：由氨基酸之间氨基与羧基脱水缩合形成的化合物；多个相连为多肽。
  • N 末端（自由氨基端）、C 末端（自由羧基端）；多肽链有方向性，序列从 N 端读到 C 端（红笔）。
  • 补充（红笔「背」）：20 种 AA 平均分子量 138，但蛋白质中优势 AA 使实际平均接近 128，减去一分子水 → 残基平均分子量 110；蛋白质含氮量与残基数估算常用此值。

2.3 肽单元与构象

  • ◇ 肽平面（肽单元）：肽键 C—N 不能自由旋转（肽键具有部分双键性质）；一个羰基碳与相邻的共 6 个原子（Cα、C、O、N、H、Cα′）处于同一平面（红笔注：肽单元是蛋白质构象的结构单元）。
  • α-C 的两个单键可自由旋转：Cα—N 旋转角称 φ，Cα—C 旋转角称 ψ；理论上 −180°~+180°，但在蛋白质中互相制约而受限（Ramachandran 图的物理基础）。
  • ◇ 分子伴侣：协助蛋白质在体内正确折叠（红笔）。
  • 蓝笔竖排边注：构象——肽键不能旋转（靠单键旋转形成的不同空间结构）；与「构型」区分（构型改变需断键）。

2.4 二级结构 ★

  • 定义：蛋白质分子中某一段肽链主链骨架相对有规律的空间结构（不涉及侧链）。
  • ☆ 维持二级结构的化学键：氢键（红笔）。
  • 类型：α-螺旋、β-折叠、β-转角、β-凸起、Ω 环、无规卷曲。
  • 1. α-螺旋（最早提出；红笔圈）：
  • 肽单元 6 原子共平面是结构基础。
  • ★ 每圈 3.6 个氨基酸残基，螺距 0.54 nm，每残基上升 0.15 nm（又称 3.6₁₃ 螺旋，氢键环含 13 个原子）。
  • 氢键：第 n 个残基的 C=O 与第 n+4 个残基的 N—H 形成链内氢键，方向与螺旋轴平行。
  • 影响因素（红笔「背」）：1) 组成 AA 的种类和侧链大小；2) Gly、Pro 不利于形成 α-螺旋（甘氨酸太柔、脯氨酸环状亚氨基）；3) 连续的 R 基带相同电荷的 AA 不易形成（如 Poly-Lys、Poly-Glu 同性相斥）。
  • 2. β-折叠（红笔：折叠状、锯齿状）：
  • 由两条以上肽段组成，肽段几乎充分延展呈锯齿状。
  • 相邻肽段间靠链间氢键维系；侧链基团交替分布于片层两侧。
  • ★ 平行/反平行两种：反平行的 N—H…O 几乎在一直线上，更稳定（红笔划线）。
  • R 基团太大或连续带相同电荷的 AA 较难形成片层（蓝笔）。
  • 3. β-转角：常出现在球状蛋白表面，使肽链回折 ~180°；由 4 个残基组成，第 1 个残基的 C=O 与第 4 个残基的 N—H 形成氢键；Gly、Pro 常出现在 β-转角中。
  • 4. β-凸起：β-折叠中多插入一个残基使连续氢键被打断形成的特殊小转折，主要出现在抗体可变区。
  • 5. 无规卷曲：肽链中无确定规律的部分，二面角多变，常构成酶的功能部位（活性中心所在）。

2.5 超二级结构与结构域

  • 蓝笔对照：模体（motif）→ 超二级结构（功能）；结构域（domain）→ 三级结构（功能）。
  • ◇ 超二级结构/模体：相邻二级结构肽段在空间上组合形成的有规则组合方式（介于二级与三级之间）。e.g. αα（α-螺旋束）、βαβ、β-曲折、发夹、HLH、Rossmann 折叠等。
  • ◇ 结构域（domain）：三级结构中相对独立、可独立行使功能的区域（荧光笔划线）；大蛋白的三级结构常由 2 个以上结构域构成。
  • 分类：α 型结构域、α/β 型、α+β 型、少 α/少 β 型（β-桶等）。

2.6 三级结构 ★

  • 定义：二级结构基础上进一步盘曲折叠形成的整体球状三维结构，包括主链和侧链的空间排布。
  • ☆ 维持三级结构的主要化学键：疏水键（疏水作用）（红笔划线）；此外有氢键、范德华力、离子键（盐键）、配位键、二硫键。
  • 疏水作用：水介质中球状蛋白的折叠类似油滴聚集，疏水残基埋在分子内部、亲水侧链分布表面（红笔「油滴」）。
  • ◇ 各种次级键的键能（kJ/mol）：氢键 12~30；离子键 10~20；疏水作用 12~20；范德华力 4~8；二硫键约 210（唯一的共价键）。
  • 球状蛋白三维结构特征（5 条）：1) 全为球状；2) 有明显折叠层级；3) 紧密的球状/椭球实体；4) 疏水侧链在内、亲水在外；5) 表面常有空穴（活性部位所在）。

2.7 四级结构

  • 亚基：具有独立三级结构的肽链（红笔圈）。
  • 四级结构 = 各亚基的空间排布 + 亚基间相互作用。
  • 亚基相同 → 同源寡聚体；不同 → 异源寡聚体。
  • ☆ 亚基聚合的作用力：主要是疏水力（疏水作用）和氢键、离子键等次级键，无二硫键（红笔）。
  • 蓝笔：除一级结构外，各层次都靠次级键维持。
  • ◇ 亚基缔合的优越性：1) 结构更稳定（表面积/体积比降低）；2) 提高遗传经济性和编码效率；3) 提高催化效率；4) 具备协同调节能力。

2.8 蛋白质结构分析技术

  • 除色谱、质谱外，还有：光谱（紫外/荧光/圆二色）、X-射线晶体学、核磁共振（NMR）、冷冻电镜（Cryo-EM）。

第三章 蛋白质的结构与功能

3.1 蛋白质分类

  • ▷ 按形状/组成分：纤维状蛋白、球状蛋白、膜蛋白（红笔下划线）。
  • 蓝笔注：按功能分：结构蛋白、功能蛋白（活性蛋白）等；同工酶类同源蛋白。

3.2 结构与功能的基本规则（红笔划线区）

  1. 结构源于序列：一级结构决定高级结构，高级结构决定功能（红笔划线，必背）。
  2. 功能源于结构：蛋白合成后折叠成特定结构并行使其功能。
  3. 结构会变化：行使功能时三维结构发生改变（构象变化）。
  4. 相似序列具相似功能：结构相似→功能相似，e.g. 同源蛋白（红笔圈）。
  5. 相似功能暗示进化相关性。
  6. 序列相似可推测共同进化起源。

3.3 一级结构是高级结构与功能的基础

    1. 一级结构是空间构象的基础（e.g. 核糖核酸酶 A 变性复性实验）。
    1. 一级结构相似 → 空间构象和功能相似，e.g. 细胞色素 C 的序列-结构-功能对应。
    1. 序列携带重要生物信息（蓝笔：可据此推测进化关系/构建系统进化树）。
    1. 关键氨基酸改变 → 功能异常：e.g. 镰刀状细胞贫血（Hbβ 链第 6 位 Glu→Val，红笔圈「贫血」）。
  • ⌄ 这种由蛋白质分子内部结构改变导致的疾病称分子病。

3.4 构象病（红笔「背」，划线贯穿）

  • ◇ 蛋白质构象改变可致病：一级结构不变、空间结构改变 → 功能受损 → 疾病（构象病/蛋白错误折叠病）。
  • 错误折叠的蛋白相互聚集、抵抗蛋白酶水解、具传染性（朊病毒 PrP 病理性传递），e.g. 老年痴呆（阿尔茨海默病）、疯牛病（海绵状脑病）。

3.5 纤维状蛋白（三个经典结构蛋白）★

  • 纤维状蛋白大多不溶于水、机械强度高；常由单一类型二级结构组成（红笔）。
  • 1. α-角蛋白（毛发、指甲、羽毛）：
  • 肽链中央形成 α-螺旋（棒状结构区 + N/C 端非螺旋区）。
  • ★ 中央区含七肽重复序列 (a-b-c-d-e-f-g)ₙ，a、d 位为疏水氨基酸（蓝笔波浪线）——疏水面促使两股螺旋相互缠绕成二聚体。
  • 相邻多肽链间由二硫键交联 → 提高强度。
  • 〔红笔〕主要作用力：疏水键 + 二硫键。
  • 2. β-角蛋白 = 丝心蛋白（蚕丝、蜘蛛丝；二级结构主要是 β-折叠）：
  • ★ 反平行 β-折叠片以平行方式堆积的多层结构，富含 Gly、Ala、Ser（红笔下划线）。
  • 重复序列 Gly-Ala/Ser；片层间距 0.47 nm。
  • 质地柔软、抗张强度高，但不能拉伸（β 折叠已充分伸展）。
  • 3. 胶原蛋白（细胞外基质结构蛋白，结缔组织）：
  • 基本组成单位：3 条 α 肽链相互扭转形成原胶原（三股螺旋）。
  • AA 组成特点：★ Gly 占 1/3；Pro、羟脯氨酸（Hyp）合计占 1/5 以上；羟赖氨酸约 0.6%；Tyr 少；缺 Trp、Cys（营养不完全蛋白）。
  • 重复序列 Gly-X-Y：X 常为 Pro，Y 常为 4-羟脯氨酸（也可以是 Lys/Hyl）。
  • Gly、Pro 含量高 → 难以形成 α-螺旋，但有利于形成三股螺旋。
  • Pro、Lys 的羟基化（需维生素 C）是为了在链间形成共价交联键，稳定三股螺旋（缺 Vit C → 坏血病）。
  • ◇ 三股螺旋：胶原蛋白特有的二级结构；三股左手螺旋相互缠绕、平行排列，形成右手超螺旋；最小的 Gly 位于螺旋内部构成紧密的轴，Pro 和 Hyp 的环状侧链位于表面（红笔划线）。

3.6 珠蛋白家族：Mb 与 Hb（大题 1/4 ★☆☆☆☆）

  • ◇ 同源蛋白有自身的不同种类，e.g. 血红蛋白 HbA、肌红蛋白 Mb、脑红蛋白 Ngb、细胞色素类。
  • 1. 肌红蛋白（Mb）的结构：
  • 一级结构：一条肽链、153 个氨基酸残基，结合 1 个血红素辅基（血红素 = 原卟啉 IX + Fe²⁺）。
  • 二级结构：8 段 α-螺旋（A~H），约占 75%；螺旋间由无规卷曲/转角连接，有 4 个脯氨酸终止螺旋。
  • 血红素配位：Fe²⁺ 共 6 个配位键——4 个与原卟啉环吡咯 N 相连，第 5 个与 F8 近端组氨酸（His F8）相连，第 6 个空置或与 O₂ 结合。
  • 三级结构：紧密球状，亲水表面 + 疏水袋；疏水袋允许 O₂ 进入而阻止 H₂O，保证 Fe²⁺ 结合 O₂ 而不被氧化为 Fe³⁺（红笔划线「疏水袋」）。
  • 2. O₂ 与 CO 的结合（红笔重点）：
  • His E7（远端组氨酸）的作用：1) 保护 Fe²⁺ 不被氧化；2) 制造空间障碍——迫使 O₂ 以 120°（≈弯曲）角度、CO 以 180°（直线）角度接近铁（笔记标 O₂ 90°/CO 120°，角度以课本为准，考点是E7 降低 CO 的亲和力，CO 亲和力由自由状态的 2 万倍降到约 200 倍）。
  • 3. Mb 的功能：O₂ 的贮存（肌细胞内）；氧合曲线为双曲线，p50 低、亲和力高。
  • 4. 血红蛋白（Hb）的结构和功能（蓝笔☆×4）：
  • ▷ 存在于红细胞，4 个亚基（α₂β₂）→ 具四级结构（红笔）。
  • 单个亚基一级结构与 Mb 差别较大（只有约 27 个位置的残基相同），但三级结构与 Mb 十分相似（红笔重点：进化保守）。
  • ★ Hb 因具有四级结构 → 正协同效应、波尔效应、别构效应，运输 O₂（红笔下划线）；氧合曲线为 S 形。
  • Hb 含 4 个血红素，能结合 4 个 O₂；每个氧结合部位有 2 个关键 His（E7、F8）和 2 个关键疏水残基（Phe CD1、Leu F4）。
  • (1) 正协同效应（红笔下划线）：一个亚基结合 O₂ 后，其余亚基对 O₂ 的亲和力增强（↑→↑↑，红笔）。
  • 解释模型两种：齐变模型（MWC， concerted）与序变模型（KNF， sequential）；都假设两种构象：紧张态 T（亲和力低）与松弛态 R（亲和力高）（红笔）。
  • T 态：四条链间结合紧密——由盐键及结合在 2 条 β 链缝隙中的 2,3-BPG（2,3-二磷酸甘油酸）造成；它们稳定 T 态，使 Hb 结合 O₂ 能力降低（蓝笔）。
  • (2) 波尔效应（红笔下划线）：可解释 Hb 在肺中吸 O₂ 排 CO₂、在组织中吸 CO₂ 排 O₂。
  • 定义：H⁺ 和 CO₂ 促进 Hb 释放 O₂ 的现象（红笔；蓝笔：结合能力下降）。
  • 原因：H⁺、CO₂ 与 Hb 的质子化位点结合，促进 Hb 从 R 态转变为 T 态。
  • H⁺ 相关的高度质子化基团：α 亚基 N 端氨基、α 亚基 His122 咪唑基、β 亚基 His146 咪唑基；T 态时三者高度质子化，O₂ 结合后质子解离。pH↓（H⁺↑）→ 稳定 T 态 → 抑制 O₂ 结合（红笔波浪线）。
  • CO₂ 两条途径：1) H₂O+CO₂ ⇌ H₂CO₃ ⇌ HCO₃⁻+H⁺（碳酸酐酶，肺部反向）；2) Hb-NH₂ + CO₂ ⇌ Hb-NH-COO⁻ + H⁺（氨基甲酰化，形成盐键稳定 T 态）。
  • (3) 别构效应（红笔下划线）：O₂ 以外的配体在血红素铁以外的位点与 Hb 结合，引起构象变化、影响 O₂ 结合能力的现象。
  • ★ 哺乳动物 Hb 的别构效应物：H⁺、CO₂、2,3-BPG、NO。
  • 蓝笔：2 个 α 亚基间的缝隙使 2 条 β 链间出现中央空穴，即 2,3-BPG 结合部位 → 保持 T 态（高原适应：2,3-BPG 增多使氧解离曲线右移）。
  • (4) 膜蛋白：占总蛋白约 30%，具识别、信号转导、运输等功能。e.g. 溶质载体 SLC、G 蛋白偶联受体 GPCR。

第四章 蛋白质的理化性质与研究方法

4.1 胶体性质

  • 蛋白质分子直径 1~100 nm，属胶体体系；有丁达尔效应、布朗运动、不能透过半透膜。
  • ★ 胶体稳定的两大因素：1) 颗粒表面带同种电荷（同电相斥）；2) 水化膜（表面亲水基团吸引水分子形成致密水化膜；荧光笔划线）。
  • ◇ 等电点 pI：蛋白质解离成正、负离子趋势相等（兼性离子，净电荷为 0）时溶液的 pH。pI 处溶解度最低。

4.2 沉淀反应

  • ◇ 除去稳定因素（电荷、水化膜）→ 蛋白质从溶液中析出。
  • 红笔：变性蛋白易沉淀；沉淀的蛋白不一定变性。
  • 沉淀方法： 1. 盐析：加中性盐（常用 (NH₄)₂SO₄）破坏水化膜，一般不引起变性（可复性）。 2. 有机溶剂沉淀（乙醇、丙酮）：破坏水化膜 + 降低介电常数，低温短时不可逆性小。 3. 等电点沉淀：pI 时净电荷为 0。 4. 重金属盐沉淀：与带负电荷的蛋白质结合成不溶性盐（碱性条件）。 5. 生物碱试剂和某些酸（苦味酸、鞣酸、钨酸、磺基水杨酸、三氯乙酸）：与带正电荷的蛋白质成不溶性盐（酸性条件）。

4.3 变性与复性（红笔 D 标记 = 必考）

  • ◇ 变性：某些物理化学因素下，蛋白质特定的空间结构被破坏（有序→无序），导致理化性质改变和生物活性丧失。一级结构（肽键）不断裂。
  • 变性因素：
  • 物理：加热、高压、紫外线、X 射线、超声波、剧烈震荡等。
  • 化学：强酸强碱、重金属盐、尿素、盐酸胍（破坏氢键和疏水作用）、三氯乙酸等。
  • ★ 变性的本质（红笔）：二硫键、次级键（非共价键）被破坏。
  • 变性现象：1) 结晶能力丧失；2) 侧链基团暴露；3) 理化性质改变（溶解度降低、黏度增加、扩散系数降低）；4) 易被蛋白酶消化；5) 生物活性丧失。
  • ◇ 变性过程存在协同效应：局部结构破坏立即引起整体稳定性骤降（蓝笔）。
  • 复性：变性程度较轻、去除变性因素后，恢复（或部分恢复）原有构象与功能。变性不可逆时——凝固（变性后絮凝物加热成坚固凝块，不再溶于强酸强碱）。
  • ★ 红笔辨析：变性蛋白不一定沉淀；沉淀蛋白不一定变性；凝固的蛋白一定已变性，且不可逆。

4.4 分离纯化与研究方法

  • 常用去除/浓缩手段：澄清、透析、超滤、凝胶过滤（蓝笔）。
  • ▷ 分离纯化总体策略（四步）：1° 预处理（提取）；2° 粗分级（盐析/等电点沉淀/有机溶剂）；3° 细分级（凝胶过滤、离子交换、吸附层析、亲和层析）；4° 结晶。
  • 按性质选择方法： 1. 分子大小：透析/超滤、离心、凝胶过滤层析（分子筛） 2. 溶解度：等电点沉淀、盐析、有机溶剂 3. 电荷：电泳、离子交换层析 4. 特异亲和力：亲和层析
  • ◇ 分子量测定：凝胶过滤层析、SDS-聚丙烯酰胺凝胶电泳（SDS-PAGE）、沉降离心（超离心）法、质谱法。
  • ◇ 含量测定：凯氏定氮法、双缩脲法、Folin-酚试剂法（Lowry）、紫外吸收法（280 nm）、染料结合法（考马斯亮蓝）、胶体金法。
  • 纯度鉴定：电泳（一条带）、HPLC、免疫法、N 端分析。
  • ◇ 一级结构测定（蓝笔划线流程）：纯化 → 拆分多肽链 → 断开二硫键 → 分析氨基酸组成 → 测 N/C 末端 → 裂解肽段 → 测各肽段顺序 → 重建完整序列 → 确定二硫键位置。

第二部分 核酸化学

第五章 核苷酸与核酸

〔便利贴〕重点：组成及性质、功能、结构及分类、DNA 结构（填空）、DNA 与蛋白质结构对比、RNA 成熟过程、核酸功能、研究方法、核酸杂交。

5.1 核酸的组成层级

  • ▷ 核酸：以核苷酸为基本组成单位的生物大分子（红笔）。
  • 元素组成：C、H、O、N、P（特征元素 P）。
  • 分子组成：碱基 + 戊糖 + 磷酸 →（核苷）→ 核苷酸 → 核酸。
  • 红笔小字：核苷酸的 3′ 排列顺序 → 遗传信息。

5.2 碱基

  • 含 N 杂环化合物：
  • 嘌呤（双环）：A、G（黄笔高亮）
  • 嘧啶（单环）：C、U、T（黄笔高亮）
  • 稀有碱基：含量很少，多为甲基化碱基；tRNA 中含量最多（页 25：tRNA 含 10%~20% 稀有碱基）。
  • 碱基性质（4 条）：1) 几乎不溶于水（芳香族杂环）；2) 强烈紫外吸收 260 nm；3) 酸碱解离——双螺旋结构的基础（红笔）；4) 互变异构（酮式 ⇌ 烯醇式，与基因突变相关）。

5.3 核苷与核苷酸

  • ◇ 核苷：碱基和核糖（或脱氧核糖）通过 β-N-糖苷键（红笔）相连；嘌呤用 N-9、嘧啶用 N-1 与核糖 C-1′ 相连。
  • 嘧啶核苷多为反式（红笔）；自由嘌呤核苷因空间位阻更易形成顺式。
  • 核苷酸：核苷的磷酸酯（戊糖羟基以酯键连接磷酸）；DNA 链中一个核苷酸 3′-OH 与另一个的 5′-磷酸缩合形成 3′,5′-磷酸二酯键（红笔波浪线）。
  • 环核苷酸：cAMP、cGMP（第二信使）。

5.4 核苷酸的功能（红笔✓ 七条）

  1. 核酸合成的原料（dNTP→DNA、NTP→RNA）
  2. 能量货币（ATP、UTP、CTP、GTP）
  3. 辅助结构成分（辅酶 NAD/FAD/CoA 含 AMP；cAMP/cGMP）
  4. 代谢调节：许多辅酶是核苷酸衍生物
  5. 活化的中间物（如 UDP-葡萄糖、CDP-甘油二酯）
  6. 作为酶的抑制剂和激活剂，参与代谢调节（红笔圈）
  7. 调节基因表达

5.5 核酸的分类与分布

  • DNA：90% 以上分布于细胞核，其余在线粒体/叶绿体（是遗传信息的载体，决定基因型）。
  • RNA：分布于细胞核与细胞质；除少数 RNA 病毒外，均转录自 DNA，多数参与蛋白质合成。
  • ◇ DNA 一种类型一种功能；RNA 多种类型多种功能（编码/非编码 RNA）。
  • ◇ Why：DNA 用 T 不用 U？——C 易脱氨变成 U，若 DNA 本身就用 U，修复酶将无法区分"原生的 U"和"突变来的 U"；用 T 则 U 一律视为损伤可被识别修复。
  • ◇ Why：DNA 2′-脱氧？——RNA 的 2′-OH 使磷酸二酯键易被碱水解，DNA 缺 2′-OH 更稳定，适于长期储存遗传信息。
  • ◇ Why：RNA 单链、DNA 双链？——(1) RNA 单链可自我折叠出多样的二级/三级结构（可与蛋白结合行使多种功能）；(2) 三维结构多样性使 RNA 能行使多种功能，而 DNA 的主要功能仅是储存遗传信息。

5.6 三种重要 RNA（占细胞总 RNA 比例）

RNA 占比 功能 特点
mRNA 2%~5% 蛋白质合成的模板 种类多、分子量差异大、代谢快（半衰期短，原核几分钟；真核一般数小时~数天）
tRNA 约 15% 活化氨基酸的载体 分子小且相似，74~95 个核苷酸
rRNA 约 80% 与蛋白组成核糖体 细胞内含量最多的 RNA

5.7 核酸一级结构

  • 通常指碱基序列（共价结构）【红笔】；遗传信息储存在碱基序列中。
  • DNA：脱氧核苷酸经 3′,5′-磷酸二酯键（红笔）连接；链的方向 5′→3′（红笔）；磷酸-戊糖交替构成骨架（红笔）。
  • 小核酸片段（<50 bp）称寡核苷酸（红笔 P 标记）。

5.8 DNA 的二级结构——双螺旋 ★

B 型双螺旋模型要点： 1. 反向平行互补双链（红笔方框）：脱氧核糖-磷酸骨架在外侧，碱基垂直螺旋轴居内侧。 2. 碱基配对：A=T（2 氢键）、G≡C（3 氢键）；嘌呤数=嘧啶数（荧光笔）。 3. 稳定力：横向——氢键；纵向——碱基堆积力（比氢键更强，红笔划线；含碱基疏水相互作用）。 4. 两链反向平行（红笔划线）；右手螺旋，螺距 3.4 nm，每圈 10~10.5 bp，相邻碱基对垂直距离 0.34 nm。 - 生物学意义：提供半保留复制的结构基础；遗传信息以碱基对序列形式储存、稳定传递。 - DNA 的多样性（构象族）： - A-DNA：与 B 型同为右手、反向平行；但每圈约 10.4 bp（不同教材 10.4~11）、直径约 2.55 nm、每 bp 上升 0.26 nm、沟槽更浅更宽。蓝笔：RNA-DNA 杂交双链或脱水时 DNA 由 B→A 转变。 - Z-DNA——左手螺旋（红笔大字）：嘌呤-嘧啶交替序列（如 CGCGCG）易形成；生物学意义：与基因调节有关（红笔）。负超螺旋（蓝笔/红笔照录：局部超螺旋张力）有利于 Z-DNA 形成；CpG 甲基化与基因表达调控相关（笔记原文「甲基化能激活基因表达」，⚠ 表述以课本为准：甲基化通常抑制转录，Z-DNA 与调控区活性相关）。 - 非标准二级结构：弯曲 DNA、十字形（回文序列）、三链螺旋、发夹、四链结构（G-四链，靠 Hoogsteen 配对，蓝笔）。

5.9 DNA 的高级结构——超螺旋

  • (二) DNA 的高级结构是超螺旋结构（红笔+黄笔高亮）。
  • 正超螺旋：双螺旋过度缠绕（拧紧）引起；负超螺旋：缠绕不足（欠旋）引起——利于复制和转录的解链（红笔旁注）；天然环状 DNA（原核）多为负超螺旋。
  • 蓝笔：拓扑异构酶改变超螺旋的数量和类型。
  • 比超螺旋（超螺旋密度）σ = (Lk − Lk₀)/Lk₀（Lk 连接数；⚠ 原笔记公式有笔误）。
  • 原核生物 DNA 多为环状，平均约 200 bp 形成一个超螺旋；真核线粒体、叶绿体 DNA 也是环状超螺旋。
  • ★ 超螺旋的意义（红笔方框）：DNA 超螺旋整体或局部的拓扑学变化及其调控，对 DNA 复制和转录有关键作用。
  • 真核基因组 DNA 的致密包装：间期以松散染色质存在；分裂期形成高度致密的染色体（串珠样，基本单位核小体）。
  • ★ 核小体组成：约 200 bp DNA + 组蛋白八聚体（H2A、H2B、H3、H4 各两分子）+ H1（锁住进出 DNA）。

5.10 RNA 的空间结构

  • RNA 空间结构取决于一级结构；种类、大小和结构的多样性远超 DNA（⚠ 笔记原文存疑照录：通常 RNA 比 DNA 小得多）。
  • RNA 通常单链，但有复杂的局部二级、三级结构（红笔）：茎环、发夹、内部环、凸起、假结等。

5.11 mRNA 的结构与成熟 ★

  • hnRNA（不均一核 RNA）：核内合成的 mRNA 初级产物，比成熟 mRNA 大得多。
  • ★ hnRNA → mRNA（黄笔高亮）：需 5′ 加帽、3′ 加尾、剪接。
  • 成熟真核 mRNA = 编码区 + 非编码区（UTR）。
  • 5′ 帽子结构 m⁷GpppNm（黄笔高亮）：转录开始不久由鸟苷酸转移酶在新生的 hnRNA 5′ 端添加。功能（4 条）：1) 防止外切核酸酶降解、提高稳定性；2) 利于起始密码子的识别；3) 使 mRNA 从细胞核转入胞质；4) 提高剪接效率。
  • 3′ 多聚腺苷酸尾 poly(A)（黄笔高亮）：约 20~200 个腺苷酸，转录完成后由 poly(A) 聚合酶添加。功能：与 mRNA 的核输出、稳定性、翻译效率有关。
  • mRNA 按碱基序列指导蛋白质中氨基酸序列的合成。

5.12 tRNA 的结构 ★

  • 一级结构特点：含 10%~20% 稀有碱基（黄笔高亮，e.g. 双氢尿嘧啶 DHU、甲基化鸟嘌呤、假尿嘧啶 ψ）；3′ 末端 -CCA-OH；5′ 末端大多为 G；有 TψC 序列。
  • 二级结构——三叶草形（红笔）：四臂四环——氨基酸臂（5′、3′ 端构成局部双螺旋，红笔）、DHU 环（D 环）、反密码子环、TψC 环、可变环（额外环）。
  • 三级结构——倒 L 形：一端是 3′-CCA（⚠ 笔记写 5′-CCA，已按事实改正），另一端是反密码子环，两端相距约 7 nm；D 环与 TψC 环构成倒 L 的转角/一横，DHU 环与反密码子环参与竖臂；部分碱基额外配对维持构象。
  • 结构与功能：3′ 端 A 与氨基酸共价结合（氨基酸臂）；反密码子识别 mRNA 的密码子。

5.13 rRNA 与核糖体

  • rRNA 种类（沉降系数）：
  • 真核：5S、5.8S、18S、28S
  • 原核：5S、16S、23S
  • 核糖体组成表：原核 70S = 50S 大亚基（23S rRNA + 5S rRNA + 31 种蛋白）+ 30S 小亚基（16S rRNA + 21 种蛋白）；真核 80S = 60S（28S+5.8S+5S+~49 蛋白）+ 40S（18S+~33 蛋白）。
  • rRNA 配对区形成局部双螺旋，间以亮环（内环）、突环、多分支环等（18S rRNA 二级结构示例）。
  • 翻译时核糖体上有 E 位、P 位、A 位（tRNA 结合部位）。
  • ◇ 核酶（ribozyme）（黄笔高亮）：具有催化功能的 RNA；天然核酶催化的大多是与磷酸二酯键有关的反应（转酯反应，蓝笔），功能一般为 RNA 的加工（剪接）；大多数核酶属自催化，绝对需要二价金属离子 Mg²⁺ 或 Mn²⁺。

5.14 核酸的功能（红笔 D 标记）

  • RNA 多样化功能：(1) rRNA——核糖体组分 (2) mRNA——模板 (3) tRNA——氨基酸载体 (4) 参与 RNA 前体加工（snRNA、核酶）(5) 基因表达调控（miRNA、siRNA 等）(6) 参与蛋白质生物合成（红笔）。

第七章 核酸的理化性质与研究方法

7.1 水解（黄笔高亮）

  • 核酸的酯键、糖苷键均可水解，糖苷键更易。
  • 1) 酸水解：糖苷键 > 磷酸酯键（对酸敏感程度）；嘌呤糖苷键 > 嘧啶糖苷键。蓝笔：DNA 怕酸，会发生脱嘌呤作用。
  • 2) 碱水解：RNA 的磷酸二酯键对碱异常敏感（2′-OH 参与分子内转酯），得 2′-和 3′-核苷酸混合物；DNA 对碱不敏感（无 2′-OH）。
  • 3) 酶促水解（主要，红笔）：非特异性——磷酸二酯酶；特异性——核酸酶（DNase / RNase；内切酶——△限制性内切酶、外切酶）。右下大字：核酶（RNA）。

7.2 酸碱解离、沉淀、紫外吸收（黄笔高亮）

  • 酸碱解离：碱基解离、核苷解离、核苷酸解离（多磷酸基 → 酸性）。
  • 沉淀：乙醇、异丙醇可沉淀核酸。
  • ★ 核酸在 260 nm 有强烈吸收（蓝笔：蛋白质在 280 nm）。OD260 用途：1) 浓度测定；2) 纯度鉴定——DNA：OD260/OD280 ≈ 1.8；RNA：≈ 2.0。

7.3 变性、复性与杂交 ★

  • 变性：DNA 双链→单链（红笔）；实质：破坏氢键、碱基堆积力，一级结构不变（蓝笔）。
  • 变性因素：高温（热变性）、强酸强碱（pH<2 / pH>11，红笔）、甲醇、尿素。
  • 变性后理化性质变化：OD260↑——增色效应（☆☆，碱基暴露）、比旋度下降、黏度下降、浮力密度升高。
  • ★ 热变性与 Tm：OD260-温度呈 S 形「跃迁式」解链曲线；Tm = OD260 达最大增量 50% 时的温度。
  • Tm 的影响因素（蓝笔☆）：1) DNA 均一性↑ → Tm 范围变窄（熔解陡）；2) GC 含量↑ → Tm↑（G≡C 三个氢键）；3) 介质离子强度（离子强度↑ → Tm↑）；4) 双螺旋长度。
  • 复性：缓慢降温（退火，红笔圈）→ 单链重新配对 → 减色效应（低色效应）（红笔）。影响复性速度：分子量↑ 复性↓；浓度↑ 复性↑；序列复杂度↑ 复性↓（⚠ 已按事实修正原笔记方向）。
  • 分子杂交：不同来源的单链形成杂交双链。e.g. DNA1 加热变单链，与 DNA2 缓慢退火形成杂化双链；Southern blot（DNA）、Northern blot（RNA）。

7.4 分离纯化原则（红笔）

  • 温度不可过高；pH 5~9；避免过低离子强度（保持一定盐浓度稳定双链）⚠ 原笔记此处存疑；减少物理剪切（摇动、吸管）；加 EDTA 抑制核酸酶。

第三部分 酶化学

第八章 酶学

〔便利贴〕重点：金属离子的作用；酶小结；催化性质——特征、学说、活化能、活性中心。

8.1 酶的概念与化学本质

  • ▷ 酶：由活细胞合成的、对其特异底物起高效催化作用的蛋白质/核酸（红笔圈「高效」）。功能——催化作用；化学本质——绝大多数是蛋白质，极少数是 RNA（核酶）。
  • 蓝笔：酶催化通式 E + S ⇌ ES → E + P。
  • 酶是蛋白质的证据（5 条）：酸碱水解终产物为氨基酸、能被蛋白酶水解而失活、变性失活、两性电解质、不能透过半透膜、有蛋白质呈色反应。

8.2 酶的组成 ★

  • 单纯酶：仅由氨基酸残基组成，e.g. 脲酶、淀粉酶、核糖核酸酶（红笔）。
  • 结合酶（全酶）= 酶蛋白 + 辅助因子：
  • ★ 酶蛋白决定反应的专一性；辅助因子决定反应的种类和性质（红笔大箭头，必背）。
  • 辅助因子 = 有机小分子（辅酶/辅基）+ 无机金属离子。
  • 辅酶与酶蛋白结合松（可透析分离）、辅基结合紧（红笔）。
  • ◇ 金属离子是最常见的辅因子（红笔）：作用——稳定酶构象、参与组成活性中心、传递电子、连接底物与酶、中和电荷等。
  • 小分子有机物：传递电子、质子或基团（e.g. NAD⁺、FAD、TPP、磷酸吡哆醛）。
  • 单体酶 / 寡聚酶 / 多酶体系：单体酶只有一条肽链但可有多个活性（多功能酶，e.g. 哺乳动物脂肪酸合酶——蓝笔）；寡聚酶由两个以上亚基以非共价键结合；多酶体系是一系列酶按顺序组成的复合物（e.g. 丙酮酸脱氢酶系）。

8.3 酶催化特征 ★

  • 与一般催化剂相同：反应前后本身不变；只催化热力学允许的反应；只加快到达平衡的速率，不改变平衡点。
  • 生物催化剂的特点（红笔！）：高效性（更有效降低活化能；蓝笔：无需高温）、专一性、可调节性（对酶生成/降解量的调节、酶原激活、条件温和下反应、对调节敏感易失活——红笔）。
  • ▷ 活化能：一定温度下 1 mol 底物变成活化态（过渡态）所需的自由能。

8.4 必需基团与活性中心 ★（大题）

  • ▷ 必需基团：酶分子中与酶活性相关的化学基团（氨基酸残基侧链基团）。
  • ▷ 活性中心（活性部位）：酶分子上与底物结合并直接起催化作用的空间区域（蓝笔：稳定反应的过渡态）。
  • 组成：结合基团（结合底物，形成酶-底物复合物）+ 催化基团（催化反应）。
  • 必需基团 { 活性中心内：结合 + 催化；活性中心外：维持酶的空间构象 }（黄便利贴图示）。
  • ★ 活性中心特征（6 条，红笔部分）： 1. 三维实体，通常由一级序列上不相邻的残基在空间上靠近组成（多位于无规卷曲区，红笔） 2. 只占酶体积的很小一部分（约 1%~2%） 3. 是酶表面的裂缝/凹穴/口袋，其中多为疏水氨基酸残基（微环境），也有少量极性残基参与结合与催化 4. 与底物靠多次级键结合：氢键、疏水作用、范德华力（偶有离子键） 5. 专一性取决于活性中心与底物结构的互补性（红笔） 6. 构象不是固定不变的，有一定柔性

8.5 酶的专一性 ★

  • 一种酶仅作用于一种/一类化合物或一种特定化学键。
  • 绝对专一性：仅作用于一个特定底物，e.g. 脲酶只水解尿素（红笔）。
  • 相对专一性：作用于一类化合物或一种化学键，e.g. 胰蛋白酶（水解碱性氨基酸羧基侧的肽键，⚠ 原笔记此处字迹不全）。
  • 立体专一性：只作用于立体异构体中的一种——旋光异构专一性、几何异构专一性。
  • ★ 专一性学说（红笔）：锁钥学说（活性中心构象刚性不变）、诱导契合学说（底物诱导酶构象改变后契合——主流）、三点附着学说（与 3 个结合点都匹配才有催化活性，解释立体专一性）。

第九章 酶动力学

〔便利贴〕酶促反应、米氏方程（Km）、抑制剂、激活剂。

9.1 影响酶促反应速率的因素

  • 红笔注：内因——酶的浓度、结构；外因——底物浓度、温度、pH、抑制剂、激活剂。
  • 酶浓度：v ∝ [E]（直线）。
  • 底物浓度：矩形双曲线（低 [S] 时 v∝[S]，高 [S] 时趋于 Vmax，红笔）。
  • 其他：pH（钟形曲线，有最适 pH）、温度（有最适温度）、抑制剂、激活剂。

9.2 米氏方程 ★★

  • 推导前提（3 条）：① 初速率（v 与 [S] 成正比阶段）；② 稳态——ES 浓度恒定；③ 服从质量作用定律。
  • ★ 米氏方程：V = Vmax[S] / (Km + [S])
  • Km 的意义（红笔 D 标记）：
  • 当 V = Vmax/2 时，Km = [S]（米氏常数的数值定义）。
  • ▷ 酶的特征性常数：只与酶本身、底物种类和反应环境（温度、pH、离子强度）有关，与酶浓度无关。
  • ▷ 表示酶与底物的亲和力（红笔）：Km↓ 亲和↑ 催化↑；Km↑ 亲和↓。
  • b. 判断酶的专一性和天然底物（Km 最小者最适）；c. 判断抑制剂类型；d. 判断代谢反应的方向与途径；e. 催化可逆反应的酶，两个方向 Km 不同，Km 小的方向为主要方向（蓝笔：途径底物）；由 Km 可知测酶活所需底物浓度（一般 [S] >> Km）。
  • Vmax：酶被底物完全饱和时的反应速率；E+S ⇌ ES → E+P 中 Vmax = k₃[E]（红波浪线）。
  • kcat（转换数）：单位时间内每个酶（活性中心）催化转化的底物分子数；酶催化效率 = Vmax/[E] = kcat（红笔）。
  • kcat/Km：酶的催化效率常数，反映酶趋近"完美酶"的程度（红笔圈「完美」）。

9.3 抑制剂 ★☆（大题 1/4）

  • ▷ 抑制剂：能使酶催化活性下降而酶量（酶蛋白）不变的物质（红笔下划线）。
  • (一) 可逆性抑制剂（蓝笔☆☆☆☆）：以非共价键与酶/酶-底物复合物可逆结合，可通过透析、超滤除去（红笔）。
  • 1. 竞争性抑制剂：与底物结构和化学性质强相似，竞争酶的活性中心；抑制程度取决于 [I] 与 [S] 的相对比例（红笔）。动力学：Km↑（表观），Vmax 不变。双倒数图：直线交于纵轴（1/Vmax 不变，斜率变大）。
  • 2. 非竞争性抑制剂：既能与游离酶 E 结合，也能与 ES 结合（结合在活性中心以外的必需基团，红笔：不是结合在活性中心上）；底物与抑制剂间无竞争。动力学：Km 不变，Vmax↓。双倒数图：交于横轴。
  • 3. 反竞争性抑制剂：仅与 ES 结合（不能与游离酶结合），使 ES 不能转变为产物。动力学：Km↓，Vmax↓（二者同比例下降，双倒数图平行线）。
  • ★ 〔红笔〕可逆抑制作用比较表（必背）：

  • (二) 不可逆性抑制剂：通常以共价键与酶活性中心的必需基团结合，使酶永久失活（划线）。四种类型： 1. 基团特异性抑制剂：与底物无结构相似性，专一修饰活性中心必需基团，e.g. 有机磷化合物（DFP）修饰丝氨酸的 -OH（胆碱酯酶失活）；解毒剂解磷定（⚠ 原笔记此句潦草，按教材补全）。 2. 底物类似物抑制剂：结构与底物类似，e.g. TPM（⚠ 原笔记字迹不全，教材常例：TPCK 修饰胰蛋白酶的 His）。 3. 过渡态类似物抑制剂：与反应过渡态极为相似，与酶的结合比底物更紧（最强的抑制剂设计思路）。 4. 自杀型（机制性）抑制剂：作为酶的底物被催化，转变成有反应活性的基团后反过来使酶失活，e.g. 青霉素（抑制转肽酶）。

9.4 激活剂

  • 定义：使酶由无活性→有活性，或提高酶活性的物质。
  • 种类：必需激活剂（无它酶无活性，e.g. 多数激酶的 Mg²⁺）；非必需激活剂（增强已有活性）。
  • 常见：无机离子（金属、非金属离子，e.g. Cl⁻ 激活唾液淀粉酶）；小分子（e.g. 胆汁酸盐、半胱氨酸/还原型谷胱甘肽 ⚠ 原笔记此处字迹不全）；蛋白质大分子（使酶原激活的蛋白酶）。

第六章 酶的催化机制（红笔标记；大题 1/4）

6.1 过渡态与酶的亲和力

  • ▷ 过渡态：不稳定的高能状态（底物经活化达到的状态）。
  • ▷ 酶与过渡态的亲和力比与基态（底物）大得多——这是酶降低活化能的本质（红笔：过渡态的稳定）。

6.2 过渡态稳定的化学机制（六种）★☆

  1. 邻近定向效应：多个底物同时结合在活性中心上，相互靠近并采取正确的空间取向；提高底物有效浓度，使分子间反应近似分子内反应，加快反应（划线）。
  2. 广义酸碱催化：水分子以外的分子/基团作为质子供体或受体参与催化；pKa 接近反应 pH（≈7）的基团是最有效的广义酸碱催化剂（红笔）；把质子转移给过渡态中间体可使其稳定（划线）。
  3. 静电催化（静电稳定）：酶用自身带电基团中和过渡态形成时产生的相反电荷，稳定过渡态；有时靠静电把底物引入活性中心（划线）。
  4. 金属催化：约 1/3 的酶需要金属离子（金属酶/金属激活酶，红笔）；金属离子以 5 种方式参与：Lewis 酸（接受电子对）、静电催化（结合带负电基团）、作为电子受体/供体参与氧化还原、通过底物的"屏蔽"降低静电斥力、稳定酶构象（⚠ 末条原笔记被遮挡，按教材补全）。
  5. 共价催化：酶与底物暂时形成不稳定的共价中间物（亲核/亲电催化），改变反应路径降低活化能（划线）。
  6. 底物形变：酶诱导底物分子内敏感键变形、更加敏感（接近过渡态）（划线）。

第十二章 酶活性的调节

12.1 酶量的调节（"量变"）

  • 酶浓度变化：控制酶蛋白基因的表达（诱导与阻遏）和酶分子的降解（红笔划线）。
  • 同工酶：催化相同反应、但分子结构和理化性质不同的一组酶（e.g. LDH 五种四聚体）。

12.2 酶活性的调节（"质变"）★

在不改变酶量的前提下调节已有酶的活性，包括别构调节、共价修饰、水解激活。

  • 1. 别构调节：代谢物与酶活性中心以外的别构部位（别构中心，蓝笔圈）非共价（红笔：非共价反应）结合，使酶构象改变、活性改变。别构效应剂分别构激活剂/别构抑制剂。
  • 底物本身作为效应剂 → 同促效应（异促效应：效应剂是其他代谢物）。
  • ★ 别构酶常为多亚基寡聚体，具协同效应，动力学曲线呈 S 形，不遵循米-曼氏动力学（红笔）。
  • ▷ 反馈抑制：别构调节最多见于代谢途径的反馈抑制——终产物作为别构抑制剂抑制途径前段限速酶。
  • 2. 共价修饰调节：在其他酶催化下，酶蛋白上某些基团发生可逆共价结合。e.g. 磷酸化/去磷酸化（红笔：最常见）、腺苷化、乙酰化/去乙酰化、-SH ⇌ -S-S（红笔划线）。特点：级联放大效应（红笔）。
  • 3. 水解激活（酶原激活）（红笔划线）：
  • 酶原：细胞内合成或初分泌时无活性的酶前体。
  • 激活机理：酶原经特异肽键断裂，水解掉 1 个/几个肽段 → 分子构象改变 → 形成或暴露出活性中心（划线）。e.g. 胰蛋白酶原→胰蛋白酶（肠激酶启动）。
  • 生理意义：(1) 保护机体组织自身（消化酶不消化自身细胞）；(2) 保证酶在特定部位/环境中发挥催化作用（在合适时间地点激活）；(3) 是酶的储存形式。
  • 补：4. 同工酶/抑制剂的调节（⚠ 原笔记整行辨认困难）；5. 酶的聚合与解聚（如乙酰辅酶A羧化酶）。
  • 〔便利贴〕酶调节分类树：活性调节（酶原激活、别构/变构酶、共价修饰）+ 含量调节（同工酶、酶蛋白合成的诱导与阻遏、酶降解调控）。

12.3 别构酶的动力学性质

  1. 动力学曲线为 S 形（划线）
  2. 有别构效应剂，通常与酶非共价结合（划线）
  3. 效应剂使活性呈双向变化（激活/抑制）
  4. 温和变性导致别构效应消失（红笔圈注）
  5. 通常为寡聚体（红笔圈注）
  6. 与非别构酶相比，对底物浓度变化更敏感（⚠ 原笔记此处字迹不全）

第四部分 糖类、脂类与生物膜

第十五章 糖类

15.1 糖的概念与分类

  • ▷ 糖的化学本质：多羟基醛或多羟基酮及其衍生物，通式 (CH₂O)ₙ（n≥3）（红笔圈）——即碳水化合物。
  • 分类：单糖、寡糖（2~10 个单糖）、多糖、衍生糖（结合糖）。
  • e.g. 单糖：葡萄糖、果糖（不能水解/水解 1 个分子）；寡糖：麦芽糖、蔗糖、乳糖（水解 2 个分子）；多糖：水解 20 个以上；结合糖：糖蛋白、糖脂（结合蛋白质、脂质）。
  • ★ 各单糖间以脱水缩合形成的糖苷键相连（红笔★）。

15.2 单糖的结构

  • D/L 构型（红笔：天然糖均为 D 型）：以离羰基最远的手性 C 为准，Fischer 投影中该碳 —OH 在右为 D 型、在左为 L 型。
  • 二羟丙酮：唯一无手性 C 的常见单糖（酮糖，C=O 居中）。
  • 仅一个手性 C 构型不同的非对映体互称差向异构体（e.g. 葡萄糖与甘露糖为 C2 差向异构体）。
  • 环状结构：分子内羟基与羰基发生快速可逆的亲核加成，形成半缩醛/半缩酮（环状）。
  • 新形成的手性 C 称异头碳（异头中心）；其上形成的异构体称异头物：
    • α 异头物：异头碳上的 —OH 与最末手性碳的 —OH 取向相反（红笔圈）
    • β 异头物：取向相同（红笔圈）
  • ★（红笔★★）D 型异头物最末的 —CH₂OH 在环（Haworth 投影）上方；L 型在下方。
  • 葡萄糖环化 → 六元环吡喃糖；果糖、核糖 → 五元环呋喃糖（蓝笔）。

15.3 单糖的性质

  • 变旋现象：异头物（α/β）在溶液中通过开环-再成环互相转变，达到平衡，使旋光度改变。
  • 还原反应：Benedict 试剂（Cu²⁺ 碱性液）将醛糖氧化成糖酸，Cu²⁺→Cu₂O 砖红色沉淀，临床上检测血糖/尿糖（半缩醛羟基具还原性→还原糖）。
  • 成糖苷：环状单糖的半缩醛（半缩酮）羟基与另一化合物的羟基（等）脱水缩合形成缩醛/缩酮——糖苷；糖苷键可通过 O、N、S 或 C-C 相连（O-苷、N-苷、C-苷）；糖苷无变旋、无还原性。〔红笔〕键型记法：α-(1→4)、α-1,4 等。

15.4 重要单糖与寡糖

  • 己糖：葡萄糖、果糖、半乳糖（红笔注）。
  • 寡糖（2~10 个单糖，糖苷键连接）三个结构要素：1) 组成单糖的种类（D/L、呋喃/吡喃）；2) 连接键的类型（α/β 及位置）；3) 是否有游离异头碳（还原端/非还原端）。
  • 命名 3 种方式：① 反映单糖名称+成键异头碳构型，如 O-α-D-葡萄糖-(1→4)-D-葡萄糖；② 区分呋喃环/吡喃环；③ ★ 标明糖苷键连接的碳原子位置（如 1→4、1→6）（⚠ 原笔记整句辨认不全，按教材补全）。
  • 常见二糖/三糖（红笔划线）：蔗糖、乳糖、麦芽糖、海藻糖。

15.5 多糖

  • 同多糖：水解只产生一种单糖；杂多糖：产生一种以上（蓝笔「杂」）。
  • ★ 糖苷键的类型与多糖的结构、功能、溶解性相关（红笔划线）。
  • 多糖特点（红笔划线）：多数无还原性（仅一端有还原端）、无变旋现象；分子量大，大多不溶于水；只有 1 个还原端 + 多个非还原端（支链多糖）。
  • 1. 淀粉（植物储能多糖）：
  • 直链淀粉：葡萄糖经 α-1,4 糖苷键连接的线性分子（红笔划线），卷曲成螺旋（与碘显蓝色）；一端还原端、另一端非还原端。
  • 支链淀粉：α-1,4 为主 + α-1,6 糖苷键分支（红笔划线）；每 24~30 个残基一个分支点（⚠ 原笔记「分支点处以 α-1,6 糖苷键连接」——原文辨不出，按教材补正）；只有 1 个还原端，多个非还原端。
  • 2. 糖原（动物储能多糖）：结构与支链淀粉相似但分支更密（约每 8~12 个残基一个分支） → 溶解性更好、水解更快、有更多非还原端 → 便于糖原磷酸化酶同时从多个末端动员（⚠ 原笔记此处字迹不全，按教材补全）。
  • (二) 结构多糖： 1. 纤维素：植物细胞壁主要成分；葡萄糖经 β-1→4 糖苷键连接的线性多糖，平行排列成片层（氢键网络）。 2. 几丁质（壳多糖）：N-乙酰-D-葡萄糖胺的均聚体，β-1→4 连接；存在于真菌细胞壁和节肢动物外骨骼（⚠ 原笔记「动物和〔真菌〕细胞〔壁〕」）。
  • (三) 杂多糖（糖胺聚糖等）：果胶（平行排列，半乳糖醛酸）；糖胺聚糖：透明质酸、硫酸软骨素、硫酸皮肤素、硫酸乙酰肝素；肝素（抗凝血）。
  • 六、复合糖（糖复合物）： 1. 糖蛋白：蛋白质为主、糖含量较低（糖链短而分支）；糖链特征是细胞的标记/标签（血型、识别）。
    • ★〔红笔方框〕糖肽键：连接糖链还原端残基与多肽链氨基酸残基的共价连接：
    • N-糖苷键：N-乙酰葡萄糖胺的 C1 与天冬酰胺（Asn）的酰胺 N 相连
    • O-糖苷键：单糖异头碳与含 -OH 氨基酸（Ser/Thr，及羟赖氨酸）的羟基相连 2. 蛋白聚糖：糖为主（糖胺聚糖与核心蛋白共价相连）；是结缔组织主要成分，在胞外基质形成网状、提供强度与韧性。 3. 肽聚糖：细菌细胞壁的刚性骨架成分（NAG-NAM 交替 + 短肽交联）。

第十六章 脂类

16.1 脂的分类

  • ▷ 定义：不溶于水而溶于非极性溶剂的生物有机分子（划线）。
  • 分类 A：简单脂（脂肪酸+醇形成的酯）、复合脂（简单脂+非脂组分）、异戊二烯脂类。
  • 分类 B：储存脂（三酰甘油、蜡）、膜脂（磷脂、鞘脂、糖脂）、活性脂类（激素、脂溶性维生素等有生物活性的少量脂质）。

16.2 三酰甘油与脂肪酸（划线标注）

  • ▷ 三酰甘油（脂肪）= 甘油 + 3 脂肪酸；还原程度高（⚠ 原笔记此处辨不出，按事实补正：高度还原、疏水，是高效储能分子），氧化释能多、热值高。
  • ★ 脂肪酸命名（红笔）：碳原子数：双键数目 Δ双键位置，e.g. 18:1Δ⁹（油酸，第 9-10 碳间一个双键）。
  • 性质：烃链越长熔点越高；顺式双键越多（不饱和度越高）熔点越低（链弯曲难紧密堆积）。
  • ▷ 蜡：长链脂肪酸 + 长链一元醇形成的酯（划线）。

16.3 磷脂与鞘脂（膜脂，划线标注）

  • (1) 甘油磷脂（磷酸甘油酯）：甘油骨架 + 2 个脂肪酸（C1、C2 酯键）+ C3 磷酸及醇基 X。
  • X = H：磷脂酸（3-sn-磷脂酸）。
  • X = 极性/带电醇：胆碱（磷脂酰胆碱=卵磷脂）、乙醇胺（脑磷脂）、丝氨酸、肌醇等。
  • ★ 特性——两亲分子（红笔划线）：磷酸基团带负电、胆碱/乙醇胺部分带正电、丝氨酸部分带负电、肌醇不带电（红笔划线）。
  • 水解甘油磷脂的酶：磷脂酶（A1、A2、C、D，⚠ 原笔记此行不确定，按教材补全）。
  • 常见甘油磷脂（红笔划线）：磷脂酰胆碱、磷脂酰乙醇胺、磷脂酰丝氨酸。
  • (四) 醚甘油磷脂：一条烃链以醚键连接（如血小板活化因子、缩醛磷脂）。
  • (五) 鞘脂类（红笔框注）：
  • 骨架是 C18 氨基醇（鞘氨醇），其氨基经酰胺键连接长链脂肪酸 → 神经酰胺（红笔划线）。
  • 极性头基在鞘氨醇 C1 上：磷酸酯键连接 → 鞘磷脂；糖苷键连接 → 鞘糖脂（红笔划线）。
  • 鞘氨醇 C3 带三个特征基团（-OH、-NH₂、-CH₂OH 区域）⚠ 原笔记此处辨认不全。
  • 鞘脂衍生关系图（红笔）：鞘氨醇 --(+FA)--> 神经酰胺 --(+P-X)--> 鞘磷脂；--(+糖)--> 鞘糖脂（葡萄糖脑苷脂、神经节苷脂等）。
  • 三、萜类与类固醇（划线标注）：
  • (一) 萜类：由一个或多个异戊二烯单元组成，直链或环状（红笔划线）。结构式 CH₂=C(CH₃)-CH=CH₂。
  • (二) 类固醇（甾体）：母核为环戊烷多氢菲（三个六元环+一个五元环，红笔圈注）。
    • 结构特点：C3 有羟基或酮基；C17 有侧链；C4-C5 或 C5-C6 间常为双键。
    • 固醇：C3 有羟基、C17 有 8~10 个碳的侧链。
    • (1) 胆固醇：两亲分子但极性头基很小，甾核+C17 烃链是刚性平面——调节（限制）膜流动性；是血液中脂蛋白的成分，与动脉粥样硬化沉积有关（红笔划线）。
    • (2) 植物固醇：结构与胆固醇相似（C17 侧链不同，C24 有乙基/甲基），能抑制胆固醇的吸收（红笔划线）。

16.4 生物膜

功能（红笔划线）：选择通透性屏障；为功能不同的细胞器提供独立场所；能量转换、神经传递、信号转导。

(一) 组成： - 主要由蛋白质、脂类、糖类组成；功能越复杂的膜蛋白质种类和含量越多（红笔划线）。 - 膜脂包括：磷脂、鞘脂、胆固醇；磷脂以甘油磷脂为主，其次是鞘磷脂（红笔划线）。 - 不同细胞器膜脂组成有差异（⚠ 原笔记此段辨认不全）：线粒体内膜富含心磷脂（二磷脂酰甘油）；核膜、内质网膜、细胞膜胆固醇含量较高。 - 膜蛋白：外周（周边）蛋白——不具跨膜区段，通过非共价相互作用/共价锚附着于膜表面；内在（整合）蛋白——镶嵌或贯穿脂双层（跨膜蛋白）。 - 外周蛋白的共价锚定方式（a-d，⚠ 多处辨认不全，按教材补全）：脂酰化（N 端 Gly 的酰胺键连脂肪酸）、异戊二烯化（C 端 Cys）、棕榈酰化（C16 酯键）、GPI 锚（C 端经乙醇胺-寡糖-磷脂酰肌醇共价连接）。

(三) 脂双层的自发装配： - 磷脂尾部靠疏水作用聚集，头基亲水与水形成氢键——疏水效应驱动；脂双层是最低能量构象（红笔划线），自发形成并能自我封闭。

(三)〔编号照录〕膜组分的不对称分布： - 不对称分布导致膜两侧电荷和流动性的差异（红笔划线）； - 与膜蛋白的定向分布和功能有关（红笔划线）。

(四) 膜脂的流动性： - 膜脂运动方式：1) 磷脂分子内运动（烃链旋转、异构化）；2) 侧向扩散（同一层内，快）；3) 翻转运动（两层之间，慢，需翻转酶，红笔划线）。 - ★ 相变温度：膜脂从晶胶态（有序）→ 液晶态（无序）的温度（红笔划线）。 - 影响流动性：脂肪酸链越长、饱和度越高 → 范德华力强 → 流动性↓；不饱和脂肪酸（顺式双键使链弯曲）→ 流动性↑（红笔划线）。 - 胆固醇对流动性双向调节：高于相变温度时限制流动（刚性），低于时防固化。无胆固醇（原核）的膜通过改变脂肪酸不饱和比例来调节流动性（红笔划线）。 - e.g. 大肠杆菌温度适应：温度变化诱导脂肪酸脱饱和酶基因表达，改变不饱和脂肪酸比例（红笔划线）。 - 流动镶嵌模型（划线）：1) 膜是脂类（主要磷脂）和蛋白质组成的动态结构；2) 磷脂双分子层是流动的基质；3) 磷脂与蛋白质能以多种形式相互作用；膜蛋白也可侧向扩散。

跨膜运输： - ▷ 被动运输——顺浓度梯度；主动运输——逆浓度梯度（耗能）。 - 1. 被动运输： - 简单扩散：非极性小分子（O₂、N₂、CO₂）、不带电极性小分子（乙醇、甘油、水）。 - 易化扩散（载体蛋白介导）：不带电极性大分子（葡萄糖转运体 GLUT）、带电小分子（氨基酸）。 - 通道运输：带电离子（Na⁺、K⁺、H⁺、Cl⁻ 等，经离子通道）。 - 2. 主动运输： - 初级主动运输：直接消耗 ATP，e.g. Na⁺/K⁺-ATP 泵： - a. 每消耗 1 ATP，泵出 3 Na⁺、泵入 2 K⁺（逆浓度梯度，红笔划线） - b. 维持膜电位差（动作电位的基础） - c. 静息状态下消耗细胞约 1/3 的 ATP（⚠ 原笔记「25%」，教材常写 1/3 或 20%~30%，神经元更高） - d. 维持渗透压，并为次级主动运输（协同运输）提供电化学梯度（红笔划线） - 次级主动运输：依赖某离子（Na⁺）顺浓度梯度的电化学势能驱动（同向：葡萄糖/氨基酸吸收；反向：Ca²⁺/Na⁺ 交换）。 - 3. 大分子运输：胞吞/胞吐（囊泡运输）。

第五部分 代谢总论与糖代谢（红笔标注最密的一章）

新陈代谢总论

  1. 代谢的特点： 1) 反应条件温和 2) 高度调控（可调节） 3) 单向性/不可逆（一条代谢途径至少有一个限速步骤，红笔） 4) 代谢途径由一系列酶促反应构成
  2. 高能化合物：水解时释放大量自由能（一般指 ≥ 21 kJ/mol / 5 kcal/mol）的化合物 ⇌ 低能化合物。 - ATP 是能量货币：产生 → 储存 → 消耗（⚠ 原笔记此处辨字不全）。 - 生理条件下 ATP、ADP 与 Mg²⁺ 结合（以 MgATP²⁻ 形式）参与酶促反应。
  3. ATP 以基团转移（磷酸基团转移）的形式提供能量，而非直接水解供能。 - ADP + Pi → ATP 的再生途径：有氧氧化 → 氧化磷酸化；光合作用 → 光合磷酸化；底物水平磷酸化。

糖酵解（Glycolysis）★★

  • Q：什么是糖酵解？（红笔圈注【无氧/不需氧条件下】）葡萄糖分解为 2 分子丙酮酸的过程。
  • Q：什么是发酵？（红笔圈注【无氧条件下】）葡萄糖经糖酵解途径最终产生乙醇（酒精发酵）或乳酸（乳酸发酵）的过程。
  • ★ 10 步反应，发生在细胞质（胞质溶胶）；两个阶段：准备阶段（第 1~5 步：六碳糖→三碳糖×2，耗 2 ATP） + 产能阶段（第 6~10 步：三碳糖→丙酮酸，产 4 ATP + 2 NADH）。

  • ▷ 其它糖（果糖、半乳糖、糖原）须转化为糖酵解中间产物才能进入该途径氧化。

NADH 与丙酮酸的去路 ★

  • NADH 的去路：
  • 〔红笔圈注重点〕无氧条件：NADH 使丙酮酸还原为乳酸（乳酸发酵）或乙醛还原为乙醇（酒精发酵），NAD⁺ 得以再生，糖酵解才能持续。
  • 有氧条件：NADH 经线粒体内膜的穿梭系统进入呼吸链重新氧化：3-磷酸甘油穿梭（→FADH₂，产 1.5 ATP）/苹果酸-天冬氨酸穿梭（→线粒体 NADH，产 2.5 ATP）。
  • 丙酮酸的去路（流程图）：
  • 缺氧/发酵 → 2 乳酸（乳酸脱氢酶 LDH，NADH→NAD⁺）；或 2 乙醇 + 2 CO₂（丙酮酸脱羧酶需 TPP；乙醇脱氢酶需 NADH）。
  • 有氧 → 进线粒体 → 2 乙酰-CoA（丙酮酸脱氢酶复合体，需 NAD⁺、TPP、FAD、硫辛酸、CoA 五种辅因子，产 NADH+H⁺+CO₂）→【红笔：柠檬酸循环】→ 4 CO₂。

糖酵解的调节 ★

  • 一、己糖激酶/葡萄糖激酶水平：G-6-P 反馈抑制己糖激酶（肌肉）；肝葡萄糖激酶不受 G-6-P 抑制，受葡萄糖激酶调节蛋白（GKRP）抑制；胰岛素↑ → 促进葡萄糖进入细胞 → 激活糖原合成方向。
  • 二、PFK-1 的调节（最重要的限速酶）：
  • 别构抑制（负）：ATP（高浓度）、H⁺（低 pH）、柠檬酸；别构激活（正）：AMP、ADP、F-2,6-BP（最强的激活剂）。
  • 两个 ATP 结合位点（红笔圈：活性中心 + 别构中心）：ATP 低浓度时作底物在活性中心结合；ATP 浓度高时结合别构部位 → 抑制（红笔）。
  • 手绘图：高 ATP 时 v-[F-6-P] 曲线呈 S 形右移（协同性）。
  • ★ F-2,6-BP 的生成与降解（PFK-2 / FBPase-2 双功能酶，同一多肽链上两个活性）：
    • 胰高血糖素 →（PKA 磷酸化）→ PFK-2 活性↓ / FBPase-2 活性↑ → F-2,6-BP↓ → 抑制 PFK-1（抑制糖酵解，促进糖异生）（⚠ 原笔记把「胰高血糖素」写成胰岛素，已修正）
    • 胰岛素 → 去磷酸化 → PFK-2 活性↑ → F-2,6-BP↑ → 激活 PFK-1（促进糖酵解）
  • 三、丙酮酸激酶的调节：
  • 抑制：ATP、丙酮酸（别构）；激活：F-1,6-BP 正反馈。
  • 肝型丙酮酸激酶受共价修饰：磷酸化失活、去磷酸化激活（口诀：肝内磷酸化是失活机制；⚠ 原笔记此处辨字不全，按教材补全）。

丙酮酸脱氢酶复合体与三羧酸循环 ★★

  • 丙酮酸脱氢酶复合体：丙酮酸经特异性转运蛋白从胞质转入线粒体基质，氧化脱羧生成乙酰-CoA（红笔：连接糖酵解与 TCA）；产 NADH+H⁺ + CO₂；辅因子：TPP、硫辛酸、FAD、NAD⁺、CoA；受共价修饰（磷酸化失活/去磷酸化激活）与别构调节。

  • ★ TCA 的调节（红笔：ATP、AMP、NADH、ADP）： 1. 丙酮酸脱氢酶系：别构（乙酰-CoA、NADH、ATP 抑制；CoA、NAD⁺、AMP 激活）+ 共价修饰（磷酸化失活）+ 产物反馈 2. 柠檬酸合酶：别构（ATP、NADH、柠檬酸、琥珀酰-CoA 抑制） 3. 异柠檬酸脱氢酶：别构（★ ADP、Ca²⁺ 激活；ATP、NADH 抑制） 4. α-酮戊二酸脱氢酶系：别构（NADH、琥珀酰-CoA 抑制；Ca²⁺ 激活）

第六部分 脂代谢（脂肪酸的分解）

脂肪酸的 β-氧化 ★★

  • 部位：绝大多数组织均能进行，肝脏、肌肉最为活跃（红笔）；场所：线粒体基质（大部分）。

1° 脂肪酸的活化（红笔：消耗 ATP）

  • 脂肪酸 + CoA-SH + ATP →(脂酰CoA合成酶，位于内质网/线粒体外膜)→ 脂酰-CoA + AMP + PPi
  • ★ 消耗 2 个高能磷酸键（ATP→AMP+PPi，红笔）

2° 肉碱穿梭（限速步骤）★

  • 脂酰-CoA 不能直接穿线粒体内膜 → 肉碱（ carnitine ）转运：
  • 膜外：脂酰-CoA --(CPT-Ⅰ / 肉碱脂酰转移酶Ⅰ)--> 脂酰-肉碱 --(转位酶跨膜)--> 膜内
  • 膜内：--(CPT-Ⅱ)--> 脂酰-CoA（膜内）+ 肉碱（返回膜外）
  • ★ ★ CPT-Ⅰ 是限速酶（红笔下划线）；肉碱穿梭是脂肪酸 β-氧化的主要限速步骤（红笔下划线）；丙二酰-CoA 抑制 CPT-Ⅰ（合成与氧化不同时进行）。

3° β-氧化四步循环（红笔下划线流程：脱氢→水合→再脱氢→硫解）

步 反应 酶 产物/产能
① 脱氢 脂酰-CoA → Δ²反-烯脂酰-CoA 脂酰-CoA 脱氢酶（FAD→FADH₂） FADH₂ → 呼吸链 → 1.5 ATP（红笔）
② 水合 Δ²反-烯脂酰-CoA + H₂O → L-β-羟脂酰-CoA 烯脂酰-CoA 水合酶 —
③ 再脱氢 L-β-羟脂酰-CoA → β-酮脂酰-CoA 羟脂酰-CoA 脱氢酶（NAD⁺→NADH+H⁺） NADH → 2.5 ATP（红笔）
④ 硫解 β-酮脂酰-CoA + CoA-SH → 脂酰-CoA（少2C）+ 乙酰-CoA 硫解酶 乙酰-CoA → TCA 彻底氧化（红笔：肝内可生成酮体运往肝外氧化利用，下划线）

脂肪酸的其他氧化方式

1. 不饱和脂肪酸的氧化（红笔：需辅助酶）

  • β-氧化中途遇到顺式双键无法继续 → 两个辅助酶：
  • ★ 烯脂酰-CoA 异构酶（红笔）：顺Δ³ → 反Δ²（只有一个双键时，仅需此酶，少产 1 FADH₂）
  • ★ 2,4-二烯脂酰-CoA 还原酶（红笔）：反Δ²-顺Δ⁴-二烯脂酰-CoA + NADPH → 反Δ²-烯脂酰-CoA（多一个双键时还需 NADPH）

2. 奇数碳脂肪酸的氧化 → 丙酰-CoA

  • 奇数 C 脂肪酸经 β-氧化最后生成 丙酰-CoA（CH₃CH₂CO~CoA），三步转成 TCA 中间物： 1. 丙酰-CoA --(★ 丙酰-CoA 羧化酶，ATP、生物素，+CO₂)--> D-甲基丙二酰-CoA 2. --(消旋酶)--> L-甲基丙二酰-CoA 3. --(★ 甲基丙二酰-CoA 变位酶，辅酶为 5′-脱氧腺苷钴胺素 = 维生素 B₁₂，红笔)--> 琥珀酰-CoA → TCA

3. 过氧化物酶体的 β-氧化

  • 起始酶：过氧化物酶体氧化酶（脂酰-CoA 氧化酶，脱下的氢直接给 O₂ 生成 H₂O₂，⚠ 原笔记辨字不全按教材补全）——不产 ATP，产能以热散失。
  • ★ 超长链脂肪酸（>22C）先在过氧化物酶体中氧化缩短（至约 8C）→ 脂酰-肉碱 → 扩散/转运进线粒体继续 β-氧化（红笔下划线重点）。
  • 植物：过氧化物酶体、乙醛酸循环体（发芽油料种子将脂肪转化为糖）。
